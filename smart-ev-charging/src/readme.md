
# Smart EV Charging Network

A student software project for exploring EV charging
stations, comparing charger types and prices, and
requesting charging reservations.

## Current Features
- Charging station dashboard
- Station search and filters
- Sample vehicle battery display
- Demo booking interaction

## Technology Stack
- React
- Vite
- JavaScript
- CSS

## Run Locally
1. Install Node.js.
2. Clone this repository.
3. Run `npm install`.
4. Run `npm run dev`.

## Project Status
Prototype under development. Sample data is not
verified live charging-station data.

## Planned Features
- Interactive map
- Backend API
- Database-backed bookings
- Station recommendation algorithm
